# Support for ChatGPT SEO

Report installation questions and reproducible bugs in
[fox67-w/chatgpt-seo Issues](https://github.com/fox67-w/chatgpt-seo/issues).
This independent adaptation is maintained in this repository. Daniel Agrici is
the author of the upstream projects; this port does not promise support from
him or from OpenAI or Anthropic.

Include the edition (Codex execution, ChatGPT companion or Project instructions),
package version, operating system, Python version where applicable, the command
or small example prompt, and expected versus actual behavior. For runtime
problems, include a redacted `doctor --json` result and the first relevant error.
Name any unavailable provider/tool and whether the task used real account data
or a supplied fixture.

Issues are public. Do not include credentials, private client exports, full chat
transcripts, personal information or unredacted reports. For a security concern,
follow [Security](SECURITY.md); no dedicated private inbox or response deadline
is promised.

For account access, plan restrictions or workspace policy problems, use the
service provider's own support. A GitHub source download does not install a
plugin or grant provider access. The [getting-started guide](docs/GETTING_STARTED.md)
explains the available installation routes.
