# Security

Report concerns about ChatGPT SEO to
[fox67-w/chatgpt-seo](https://github.com/fox67-w/chatgpt-seo).

Do not post credentials, private client material, exploit details or a vulnerable
private URL in a public issue. Use GitHub's private vulnerability reporting
option if available; this project does not claim it is enabled. Otherwise,
open a minimal [security contact request](https://github.com/fox67-w/chatgpt-seo/issues/new)
with no sensitive details and request a private reporting channel.

No dedicated private inbox or response deadline is promised.
See the [Codex edition security policy](plugins/codex-seo/SECURITY.md) for
execution boundaries, URL protections and known limitations, and
[Support](SUPPORT.md) for routine bugs and installation questions.

Original upstream policies retained inside the source tree describe their own
projects and do not establish security commitments for this independent port.
